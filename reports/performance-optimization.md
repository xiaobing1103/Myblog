# 深度性能优化验收

## 本轮实测

| 页面 | 优化前请求数 | 优化后请求数 | 优化前传输量 | 优化后传输量 | 减少 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 桌面首页 | 50 | 10 | 224,434 B | 129,858 B | 42.1% |
| 手机首页 | 42 | 10 | 195,241 B | 129,858 B | 33.5% |
| Flex 文章页 | 53 | 20 | 311,638 B | 201,742 B | 35.3% |

使用同一台机器的 Chrome、本地带 Brotli 的生产预览、全新浏览器上下文，等待网络空闲后再观测 1 秒，包含视口触发的预取。PDF 另等待首个 Canvas 可见。CDP 统计不保证覆盖 iframe/Worker 的所有独立网络目标，因此表格只比较主页面，PDF 数据供诊断使用。原始数据见 `network-before.json` 和 `network-current.json`；这些结果不等于线上访问速度。

首页入口脚本 gzip 从本轮开始的 109,382 B 降至 107,887 B；相对最初升级前的 126,881 B 减少 15%。首页 HTML 为 17,649 B。框架入口体积与实际页面传输量分别统计。

## 改动

1. **按交互意图预加载**：关闭链接进入视口时的批量预取；悬停、触摸的官方预加载和客户端导航继续工作。
2. **列表只加载元信息**：首页、标签页不再为显示卡片下载文章 MDX；归档只传标题、日期和地址。归档数据从 237,844 B 减至 2,876 B。
3. **图片适配屏幕**：27 张静态大图生成多尺寸 WebP；12 张动画先展示首帧封面，点击后播放。动画原文件合计 6,515,686 B，封面合计 107,238 B；点击播放仍会下载原动画。封面与响应式图片均自动生成，原图保留。
4. **优化小资源**：首页 SVG 压缩，17 KB 的 favicon 改用约 2 KB 的 PNG，旧资源地址保留。
5. **PDF 按需读取**：使用 PDF.js 的 `disableAutoFetch` 和 `disableStream`，在支持 Range 的服务按需获取字节；翻页、搜索、下载仍可用。[选项依据](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)
6. **本地服务**：异步压缩、16 MiB 有界压缩缓存、PDF 流式响应、Range/HEAD/ETag；HTML 不缓存，带哈希的资源缓存一年，稳定名称的脚本重新验证。
7. **回归预算**：入口 gzip ≤112 KiB、首页 HTML ≤20 KiB；冷首页 ≤14 请求和 160 KiB、文章 ≤30 请求和 260 KiB，CI 自动检查。

## 使用与维护

执行 `npm run build` 会先恢复响应式图片与动画封面，随后 `npm run preview` 在 <http://127.0.0.1:3000/Myblog/> 提供预览。升级 Docusaurus 时复核博客路由包装器、预取别名和 Prism 适配，并运行完整测试与性能预算。

GitHub Pages 的响应头由平台控制；本地服务的缓存与 Range 行为不会自动变成线上配置。本站的元信息列表、预加载策略、图片和 PDF 客户端改动会随发布生效。本次未推送发布，线上尚未更新。
