## 怎么阅读英文文档

先找代码示例、参数、返回值和异常。把术语与课程中的概念配对：`request body` 是请求体，`constraint` 是校验约束，`transaction` 是事务，`repository` 是数据访问模块。

遇到版本不同的文章，先核对项目版本。Spring Boot 4 使用 Jakarta 包名；不要把旧文章的 `javax.validation` 直接复制到当前项目。

## 在线练习使用的技术

本页练习通过 [OneCompiler 官方嵌入示例](https://github.com/onecompiler/editor-embed-demo) 对接 Java 编译器。点击启动后才加载外部 iframe；代码会发送到第三方服务。可下载源代码本地执行，草稿与完成记录保存在当前浏览器。

服务的可访问性和配额由提供方决定。出现超时可重试或使用官方 Playground；不要在练习代码中放入密码或业务密钥。
