## 把状态与规则放在一起

前端常用对象保存数据，用函数修改数据。Java 中可以用类把字段和相关方法组织在一起。构造器负责创建对象时的初始状态，`private` 字段限制外部直接修改。

```java
class User {
    private final String name;
    User(String name) { this.name = name; }
    String name() { return name; }
}
```

封装的价值是守住规则。钱包余额如果可以随意赋值，那么“不能存入负数”就只能靠每个调用者自觉遵守。把检查放在 `deposit` 内部，所有调用都走同一个入口。

## 接口定义调用方式

TypeScript 的接口主要参与类型检查，编译成 JavaScript 后会被移除。Java 的接口会形成字节码层面的类型契约，实现类使用 `implements` 声明遵守它。

```java
Notifier notifier = new ConsoleNotifier();
```

变量的类型是接口，实现可以替换。后续 Spring 中的依赖注入会沿用这个思路：调用者描述需要的能力，框架帮助组装依赖。接口并不意味着每个类都必须抽一个接口，先有真实的替换或分层需求。
