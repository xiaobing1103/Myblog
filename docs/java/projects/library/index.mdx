## 最终要做出什么

| 功能 | 用户操作 | 后端需要保证 |
| --- | --- | --- |
| 登记图书 | 输入书名、作者、总册数 | 字段合法，可借数量初始等于总册数 |
| 搜索分页 | 输入关键词，切换页码 | 参数受限，稳定排序，返回总数 |
| 借出 | 为图书填写借阅人 | 库存大于零才可借，库存与借阅记录同时提交 |
| 归还 | 点击一条未归还记录 | 只能归还一次，库存不超过总册数 |
| 删除图书 | 删除无借阅历史的图书 | 已有历史时拒绝，保留数据关系 |

这里的“借阅人”作为教学文本字段保存。项目使用本机教学配置，后续多用户系统需要另外实现登录、权限与部署方案。

## 先运行一次

解压下载包，进入包含 `pom.xml` 的 `library-lab` 目录：

```sh
java --version
mvn --version
mvn test
mvn spring-boot:run
```

打开 `http://127.0.0.1:8080/`。首次启动为空书架，可录入一本书再借出。另一个终端访问 `http://127.0.0.1:8080/api/books`，观察页面背后的 JSON。

首次执行 Maven 会下载依赖，需要网络。若 8080 已被其他练习项目占用，可先停止旧服务，或使用 `mvn spring-boot:run "-Dspring-boot.run.arguments=--server.port=8081"`，并相应改为访问 8081。

## 接口速查

| 方法与路径 | 输入 | 成功响应 |
| --- | --- | --- |
| GET /api/books | 可选 q，page 默认 1，size 默认 10 | `{items,total,page,size}` |
| GET /api/books/id | 路径 id | 单本图书 |
| POST /api/books | title、author、totalCopies | 201，Book 与 Location |
| DELETE /api/books/id | 路径 id | 204，无响应体 |
| GET /api/loans | 可选 active=true/false | 最近最多 100 条借阅数组 |
| GET /api/loans/id | 路径 id | 单条借阅记录 |
| POST /api/loans | bookId、borrower | 201，Loan 与 Location |
| POST /api/loans/id/return | 路径 id | 200，归还后的 Loan |

Book 字段：id、title、author、totalCopies、availableCopies。Loan 字段：id、bookId、bookTitle、borrower、createdAt、returnedAt；未归还时 returnedAt 为 null，时间以 UTC 字符串返回。

输入不合法返回 400，不存在返回 404，无库存、重复归还或有历史不能删除返回 409。这些输入与业务失败的响应包含 `message`，前端用它显示原因。

## 开始前的任务

先用自己的话写出“借出一本书”必须同时改变的两份数据，再指出只改其中一份会发生什么。

<details>
<summary>参考答案</summary>

可借库存减一，并新增未归还的借阅记录。只减库存会丢失谁借走了书，无法正常归还；只写记录会让库存不减少，继续借出时可能超借。两项操作必须在同一事务中成功或一起回滚。

</details>
