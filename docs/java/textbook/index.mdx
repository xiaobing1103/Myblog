这套教程从“程序怎样启动”开始，逐步走到“一个 HTTP 请求怎样被校验、保存和测试”。你需要会基本的 JavaScript、终端操作和 JSON；不要求提前学过 Java 或 Spring。

**学习顺序：运行示例 → 预测输出 → 修改一个条件 → 解释结果 → 独立完成任务。** 不需要先背完整 API，也不要只复制代码后点运行。

## 每课怎么学

1. 先读目标和前置知识。不能解释前一课概念时，先回看对应示例。
2. 把标为 `Main.java` 的完整示例保存为同名文件，用 Java 21 执行 `java Main.java`。前 14 课的完整示例均提供可核对的输出。
3. 逐句阅读拆解，再合上示例完成两项课后任务；任务本身不会因为展开答案就标为完成。
4. 对照答案修正原因，至少补一个边界输入。配套在线练习使用原有 12 题，示例输出通过不等于全面正确。
5. 后四课在完整 Maven 项目内操作，代码片段旁会说明文件位置。不要把局部片段直接当独立文件运行。

推荐每次学一课。进度以“能解释、能修改、能验证”为准；日期和学习速度由你自己安排。

## 资料来源与版本

本站教材为原创中文讲解与示例，以 JDK 21 为运行基线，后端示例版本以下载项目的 `pom.xml` 为准。内容覆盖基础与第一个后端工程；并发、JVM 调优、认证授权、生产部署需要另行深入。

查语言知识看 [Dev.java](https://dev.java/learn/)，查具体方法看 [Java 21 API](https://docs.oracle.com/en/java/javase/21/docs/api/index.html)，查框架看 [Spring Guides](https://spring.io/guides/)。[Oracle 旧版 Java Tutorials](https://docs.oracle.com/javase/tutorial/) 以 JDK 8 为背景，适合补概念，旧部署方式与新版本差异需要辨别。
