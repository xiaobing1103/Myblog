## 先读哪一份

1. 想直接动手：进入[本站中文操作指南](./rest-service.mdx)，先运行 complete，再在 initial 独立完成同样的接口。
2. 想看作者原文：在线阅读官方教程，或下载原始 README.adoc。原文包含 AsciiDoc include 指令，部分引用在线公共宏，不是已展开所有宏的离线 HTML。
3. 想核对代码：比较 initial 与 complete 下的同一路径，优先看 Greeting、GreetingController 和测试，而非把所有构建文件一次读完。
4. 想做完整项目：进入[图书借阅管理台实战路线](../projects/library/index.mdx)，把单一问候接口扩展到带库存约束的借阅业务。
