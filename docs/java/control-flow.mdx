## 先看熟悉的部分

`if`、`for`、`while` 的外形与 JavaScript 很接近。新的要求是：条件必须是 `boolean`，不会自动把 `0`、空字符串或对象当成真假值。

```java
int stock = 5;
if (stock > 0) {
    System.out.println("available");
}
```

方法要说明参数和返回值的类型。没有返回值时写 `void`。这些练习使用 `static` 方法，让 `main` 可以直接调用；它不是声明“不可修改”的关键字。

```java
static int add(int left, int right) {
    return left + right;
}
```
