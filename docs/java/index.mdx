## 怎么边学边练

1. 打开章节，先看 Java 与 JavaScript 的差异。
2. 修改练习中的 `TODO`，点击“启动在线练习”。编译器就绪后，点“运行当前代码”。
3. 查看真实输出，与题目的预期输出对照；遇到错误先读编译器提示，再展开解题提示。
4. 换一个边界输入验证，再看参考答案。示例通过后，进度会保存在当前浏览器。

也可以直接进入 [Java 练习台](./practice.mdx)，集中练习 12 道题。草稿按题目分别保存，换设备或清除浏览器数据不会同步进度。

## 两种运行方式

| 学习内容 | 运行方式 | 能观察什么 |
| --- | --- | --- |
| Java 语法、对象、集合、Stream、异常 | 页面内 OneCompiler，点击后加载 | 编译错误、标准输出、示例检查 |
| Spring Boot + 数据库项目 | 下载到本机，使用 Java 21 与 Maven 运行 | 真实 HTTP 请求、数据库持久化、自动化测试 |

在线练习会把运行的代码发送到 OneCompiler；如果该服务无法访问，可以下载 `Main.java` 后执行 `java Main.java`，或使用 [Oracle 官方 Playground](https://dev.java/playground/)。Spring Boot 需要持续运行的服务进程，项目不会在静态博客中伪装成已启动。

## 本机准备

安装 JDK 21 和 Maven 后，在新终端中检查：

```sh
java --version
javac --version
mvn --version
```

本课程使用 Java 21 作为本地基线，单文件练习无需开启预览特性。后端示例使用 Spring Boot 4.1.2；版本要求见 [Spring 官方说明](https://docs.spring.io/spring-boot/system-requirements.html)。

## 学完这一轮，你应当能做到

- 解释静态类型、引用比较、接口和泛型与前端代码的差异。
- 使用集合和 Stream 处理一组订单数据。
- 把业务规则写进服务层，并用异常和 HTTP 状态表达失败。
- 运行一个包含参数校验、H2 数据库、JDBC 和测试的待办 API。

下一轮再深入并发、JVM、MySQL 索引、认证与部署。先把一个小功能做完整，再扩展系统。
