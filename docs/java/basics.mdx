## 先建立类型意识

Java 在编译时检查类型。一个变量声明为 `int` 后，不能再给它赋字符串。`var` 也只是让编译器推断局部变量的类型，类型一旦确定就不会变化。

| JavaScript 中的经验 | Java 中对应的思考 |
| --- | --- |
| `let value = 1`，之后可能换成字符串 | `int value = 1`，类型固定 |
| 数值通常是 `number` | 选择 `int`、`long`、`double` 等类型 |
| `const` 禁止重新赋值 | `final` 禁止变量重新赋值，不保证对象内部不可变 |
| 字符串用 `===` 比较 | 字符串内容使用 `equals` 比较 |

```java
int count = 3;
long totalInCents = 12900L * count;
var title = "Java"; // 推断为 String
final int limit = 10;
System.out.println(totalInCents);
```

练习统一使用 `public class Main`，文件名为 `Main.java`。`main` 是程序入口；`System.out.println` 会输出一行，便于观察结果。

## 引用与对象内容

对于对象，`==` 判断两个引用是否指向同一个对象。两个不同的 `String` 对象可以具有相同内容，因此内容比较使用 `equals`。如果变量可能为 `null`，可以使用 `Objects.equals(a, b)`，避免对 `null` 调用方法。
