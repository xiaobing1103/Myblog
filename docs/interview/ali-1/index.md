## 建议优先复习的纠错

- HTML 的 DOCTYPE 不决定 JavaScript 严格模式；HTML 解析不依赖下载 DTD。
- `b`、`i` 仍是有效的语义元素，`s`、`u` 没有从现代 HTML 中移除。
- AppCache、Flash、`keygen`、IE `hasLayout` 只作历史知识；离线应用学习 Service Worker 与 Cache API。
- Cookie 不按端口隔离，也不默认加密；本地存储会受清理、配额和隐私分区影响。
- CSS 优先级先看层叠，再比较选择器；不能把 `!important` 当成永远最高。
- BFC 不会隔离所有布局；兄弟的外边距折叠、父子的折叠需要分别分析。
- `clear:left` 与 `clear:both` 并不等价；Flex、Grid 建立各自的格式化上下文。
- 动画没有固定的 16.7ms 最小间隔；用 `requestAnimationFrame` 和时间戳适配刷新率。
- 自适应正方形和 2:1 矩形示例改用 `aspect-ratio`，修正原答案的比例问题。
