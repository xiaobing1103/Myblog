## Java：一步一步做出后端

1. 从 [环境与第一个程序](../java/textbook/01-first-program.mdx) 开始，依次完成 18 课的动手任务。
2. 到 [练习台](../java/practice.mdx) 修改代码，观察真实编译与运行结果。
3. 跟着 [7 步项目文档](../java/projects/library/index.mdx) 实现图书录入、搜索、借还、库存和测试。
4. 对照 [官方 REST 小项目](../java/open-source/rest-service.mdx) 阅读开源代码，再回到自己的项目解释设计取舍。
